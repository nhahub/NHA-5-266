Project Overview:

This project focuses on analyzing a large-scale supply chain dataset from DataCo to uncover operational insights, evaluate delivery efficiency, track financial performance, and analyze customer and geographical trends. Using a modern data stack comprising Excel, Power BI, and GitHub, the team has built an end-to-end analytics solution to identify supply chain bottlenecks and optimize overall business logistics.


Tools & Technologies: 

Data Cleansing & Transformation: Microsoft Excel, Power Query
Data Modeling & Visualization: Power BI Desktop (DAX, Star Schema Modeling)
Version Control & Collaboration: GitHub

Dataset & Key Fields:

The dataset tracks comprehensive supply chain metrics, including:
Order Details: Order Id, order date, Order Item Quantity, Sales, Order Profit Per Order
Fulfillment & Shipping: Type (shipping mode), Days for shipping (real), Days for shipment (scheduled), Late_delivery_risk, Delivery Status
Customer & Geography: Customer City, Customer Country, Order Region, Latitude, Longitude
Product Information: Product Name, Category Name, Product Price

Key Dashboard Pages & Features:

1- Financial & Sales Overview: Highlights total sales, order profit margins, top-performing product categories, and department performance.
2- Supply Chain & Delivery Operations: Evaluates shipping efficiency, compares scheduled vs. real shipping days, and monitors late delivery risk drivers.
3- Customer & Geographic Analysis: Visualizes regional sales distribution and customer concentrations globally using map integrations.
